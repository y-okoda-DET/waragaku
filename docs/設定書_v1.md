## 0. リアリティの方針

- 目標は、養成所に通っていた人、芸人、お笑いファンの3者が「あるある」と言うこと
- 出来事・台詞・数字は、調査メモにある実話や証言を「型」にして使う。実在の人物・コンビ・期のエピソードをそのまま再現しない
- 盛らない。お金は本当に赤字になり、ほとんどのコンビは漫才大会の1回戦で落ち、半分以上の同期は消える。その中で小さく勝つ気持ちよさを作る
- ルールの芯は調査で一番重かった証言に置く:「先輩といくら仲良くなっても、面白くなければ仕事には呼ばれない」【05】
- 時代は「今」（令和）。先輩の誘いを断っても昔ほど角が立たない、エゴサやネタ動画がある、といった現在の空気にする【05】【06】

## 2. キャラクリ

1. **名前**: 名前・ふりがな・呼ばれ方
2. **見た目**: 髪型・髪色・顔パーツ・体型・服（パーツの組み合わせ）
3. **経歴**: 下の10種類から1つ
4. **出身**: 地元組／上京組（上京組は家賃と仕送り事情が加わる。方言の有無も選べる）
5. **担当**: ボケ／ツッコミ、得意にしたい形（漫才／コント）

## 4. 人脈システム

### 基本ルール
- 人との関係は「**仲の良さ**」と「**認められ度**（面白いと思われているか）」の2つで持つ【05】
- 仲が良いだけだと飲みには呼ばれるが、仕事やライブには呼ばれない（「こいつは呼んだら来よる。でも全然おもろない」）
- 認められ度が上がるのはウケたときだけ。ネタ見せ、在学生ライブ、先輩の前での平場
- 両方が高い相手からは、出番、紹介、仕事が回ってくる

### 人脈の相手

| 相手 | 在学中の出会い方 | 何をくれるか |
|---|---|---|
| **先輩芸人**（複数のNPC） | 助手先輩、特別授業の講師、お目付け役、バイト先の先輩芸人、学生お笑いのOB | 奢り（食費が浮く）、ネタへの一言（経験値）、居候先、ユニットライブや自主ライブへのお誘い、1年目のバーター出演 |
| **同期** | 授業、相方見つけ会、飲み、同期LINE | 合同の自主ライブ、相方の紹介、シフト代わり、困ったときの「同期のケツは同期で拭く」 |
| **作家・劇場社員** | ネタ見せ、在学生ライブの作家票・社員票 | 選抜・劇場オーディションでの評価、1年目の出番 |
| **外の縁** | 学生お笑い、自主ライブ、バイト先 | 自主ライブの出演依頼、業界にいる友人からの紹介 |

### 上げ方と代償

| 行動 | 上がるもの | 代償 |
|---|---|---|
| 先輩の飲みに行く | 先輩の仲の良さ、たまにネタへの一言 | 体力、翌日のネタ時間。終電を逃す |
| **お礼3回**（別れ際、翌朝のLINE、次に会ったとき開口一番「この前はご馳走様でした」） | 守ると仲の良さが維持される。忘れると下がる | なし（翌朝に通知が出る） |
| 先輩の単独ライブの手伝い（2週間ノーギャラ） | 先輩の仲の良さ大、裏方を知る。まれにエキストラで舞台に立てる | 2ターン拘束、バイトに入れない。差し入れの高級菓子を持ち帰れたらラッキー |
| 先輩の引っ越しの手伝い | 仲の良さ、お下がり（服・家具）がもらえる | 体力 |
| 同期と飲む・自主ライブを打つ | 同期の結束 | お金 |
| ウケる | 認められ度（全員） | なし |

### 奢られ方のタイプ（行動の選択肢として出す）【05】
- 甘え上手:「ご飯誘って下さいよ～」。誘われやすいが、尊敬は得にくい
- 太鼓持ち: 褒めて立てる。仲の良さは上がるが、認められ度は上がらない
- キャスティング: 先輩に合いそうな同期を連れて行く。同期の仲も上がる
- バカ飲み: 盛り上げ役。体調が下がる

### 人脈が悪く働くとき
- 付き合いすぎるとネタ作りの時間が消え、面白さが伸びずジリ貧になる
- **気を遣いすぎると「無難」扱い**: 社員や先輩に気を遣う行動ばかりだと出番は安定するが、ブレイクの上限が下がる。逆に尖った選択（ケンカ、断る）は短期的に仲が下がるが「尖り」が上がる【05】
- **事務所を通さない仕事の誘い**: 顔が広いほど誘いが来る。受けるとお金になるが、1年目に発覚して謹慎になる危険がある【05】
- 1年目に後輩ができると**奢る側に回る**。売れないまま後輩に奢り続けると借金ルート【05】

## 5. 1週間の過ごし方（1ターン）

授業は自動で進む（週ごとの授業イベントが1つ起きる）。プレイヤーは空き時間に「**昼の行動**」と「**夜の過ごし方**」を1つずつ選ぶ。

**昼の行動**
| 行動 | 効果 | あるある |
|---|---|---|
| ネタ作り | ネタ帳が増える・完成度アップ | 深夜のファミレスで「お笑い向いてないのかな…」 |
| ネタ合わせ（場所を選ぶ） | 相方との関係値・ネタの完成度 | 公園（夏は蚊、警察に職務質問、ヤンキーに「芸人ちゃうん？」）／カラオケ（お金がかかるが集中できる）／ファミレス（「ファミレス行かへん？」の電話は、たまに解散話） |
| 自主練 | 能力アップ（発声・筋トレ・ダンス） | ダンスが下手だと真面目にやってもふざけて見える |
| バイト（種類を選ぶ） | お金。種類で副作用が違う | 居酒屋（まかない）／カラオケ深夜（裏でネタ合わせ）／引越し（翌日寝たきり）／コールセンター（座れるが疲れる）／エキストラ（急な呼び出し） |
| 自主ライブに出る | 度胸・外の縁・ファン | エントリー料2,000円、客席5人、受付で初めて5,000円と知る |
| ライブを観に行く | 発想力・研究 | 勉強のつもりが笑ってしまう |
| 休む | 体調回復 | |

**夜の過ごし方**: 先輩の飲み／同期と飲み／家でネタ帳を書く／エゴサ・SNS投稿／寝る

## 7. 芸風スキル（改訂版）

ゲーム内では「特殊能力」と呼ばず「芸風スキル」。武器（丸）、クセ（三角）、極み（星）をバッジの形で見分ける。
前の版の43個に、学生お笑い・人脈・あるある系を足して見直した。

**ネタ作り系（武器）**: 設定の鬼／ツカミ名人／伏線回収／天丼職人／言葉選び／量産型／時事ネタ／**勝負ネタ温存**（予選の後半に向けて強いネタを残せる）

**舞台系（武器）**: 間の取り方／声がデカい／顔芸／憑依型／早口／本番に強い／噛まない／スベり返し（スベった後の謝罪でウケる）／**出囃子のセンス**（登場時に客が温まる）

**平場・バラエティ系（武器）**: フリートーク／大喜利脳／ひな壇の鬼／リアクション芸／SNS上手／**バトル脳**（勝ち負けに熱く、バトルライブに強い）

**人脈系（武器）**: **かわいがられ**（先輩の仲の良さが上がりやすい）／**キャスティング上手**／**お礼が早い**（お礼3回を自動で守る）／**同期の要**（同期の結束が上がりやすい）／**手売り上手**（1年目のチケットとファン）

**生活・メンタル系（武器）**: 鋼のメンタル／早起き／苦学生／相方思い／雑草魂（梅組で成長が早い）／**公園の主**（屋外のネタ合わせでイベントが起きにくい）

**クセ（マイナス）**: あがり症／内輪ウケ／パクリ疑惑／遅刻魔／ネタが長い／理屈っぽい／口を触る癖／浪費家／**学生お笑い臭**（一般客にウケにくい。矯正できる）／**仕上がってる扱い**（講師のアドバイスが減る。結果を出すと解ける）／**ダメ出し無視**（直さないので選抜に入れない）／**断れない**（飲み・手伝い・怪しい誘いを断れない）／**エゴサ中毒**（本番前にやる気が上下する）

**化けるクセ**: 天然→愛され天然／毒舌→愛ある毒舌／変人→唯一無二／**学生お笑い臭→玄人殺し**（一般客への対応力を上げると、作家・審査員受けが強い武器に化ける）

**極み**: 爆笑請負人／言葉の魔術師／一発屋の素質／劇場の主／時代の寵児／**○○組の秘蔵っ子**（先輩の仲の良さ・認められ度が両方最大。1年目にバーターと居候が保証される）

## 8. 演出とUIのあるある

- 挨拶ボタンは時間に関係なく「おはようございます」
- ネタ見せの前に「何時に並ぶ？」（2時間前／1時間前／ギリギリ／わざと最後尾）
- 講師のダメ出しテキスト: 「おもんない」「状況がわからん」「パクリやろ」「言わされてる感がある」「学芸会ではない」「次からこなくていい」
- エントリー画面:「エントリー料 2,000円／ネタ時間 2:00」。足りなければ「バイトのシフトを増やしますか？」
- 予選の結果画面:「公式サイト更新待ち…」の後、自分の名前が「ない」ことで落選を知る
- スベったとき: 無音、冒頭でネタを飛ばすと会場全体が不安になる、終演後に口内炎アイコン
- ライブ後のアンケート束: 細かい通、一言だけ、全員を丸文字で褒める人
- エゴサ画面:「◯◯さん」と「◯◯ちゃん」で出てくる感想が違う
- 衣装の変遷: 卒業式のスーツ→サイズの合わないジャケット→古着の明るいジャケット→安いオーダースーツ（襟だけ色違い）

## 9. 卒業後1年目（ダイジェスト）

前の版に、次のリアルな要素を足す。

- **劇場オーディション**（隔月、数百組）と自主ライブのランク制で、少しずつ上に行く【03】【06】
- **お金は赤字**: 劇場の出番は1回数百円、交通費で消える。バイトは続ける【03】
- **3か月ルール**: 卒業後に解散・再結成すると3か月舞台に立てない【03】
- **人脈の効き方**: 先輩の仲の良さと認められ度が両方高いと、バーターの営業、ユニットライブ、居候の救済が来る。仲の良さだけなら飲みに誘われるだけ【05】
- **ファン**: 手売り、出待ち（先輩にだけいないと気まずい）、冷めた缶コーヒーの差し入れ、トレカ【06】
- **後輩ができる**: 3月に次の期が卒業し、奢る側に回る【05】【06】
- **賞レース**: 大半は1回戦敗退。結果は名前が「ない」ことで知る。3回戦に残るとお笑いファンに「青田買い」される【03】【06】
