## 1. 芸風スキル（パワプロの特殊能力にあたる仕組み）

### 名称と見せ方
- ゲーム内の名前は「**芸風スキル**」。「特殊能力」「金特」「青特・赤特」などパワプロ固有の呼び名は使わない
- 見た目もパワプロ風の青・赤の色分けを避け、次の3種類を**アイコンの形**で区別する
  - **武器**（プラス）: 丸いバッジ
  - **クセ**（マイナス）: 三角のバッジ。消すこともできるし、育てると武器に化けるものもある（下記「化けるクセ」）
  - **極み**（上位）: 武器を育てた先の特別な一つ。卒業大会の勝敗や1年目の展開を大きく動かす
- 能力値（発想力・ツッコミ力・表現力・度胸・対応力・体力）は「どれだけ上手いか」、芸風スキルは「どんな芸人か」を表す。リザルトとシェア画像で一番目立つのは芸風スキル

### 効果が出る場面
| 場面 | 例 |
|---|---|
| ネタ作り（カード） | 特定のカードが強くなる、使えるカードが増える |
| ネタ見せ・ライブ | ウケの量、ミスの確率、講師の評価 |
| イベント | 選択肢が増える（例: 「人たらし」なら講師の機嫌を取る選択肢） |
| 1年目ダイジェスト | 進むルートが変わる（例: 「ひな壇の鬼」ならテレビ出演が増える） |

**クセ（マイナス）**
| スキル | 効果 | 入りやすい場面 |
|---|---|---|

| ネタが長い | 持ち時間オーバーでゴングが鳴りやすい | カードを詰め込みすぎる |

**化けるクセ（育てると武器になる）**
| クセ | 武器になる条件 | 化けた後 |
|---|---|---|
| 天然 | 相方の関係値が高いまま卒業大会へ | **愛され天然**（ボケが外れてもウケる） |
| 毒舌 | 人たらしを持っている | **愛ある毒舌**（トーク評価が大きく上がる） |
| 変人 | 憑依型を持っている | **唯一無二**（コント評価が大きく上がる） |

**極み（上位スキル、1プレイで1〜2個）**
| 極み | 元になる武器 | 効果 |
|---|---|---|
| 爆笑請負人 | 本番に強い＋ツカミ名人 | 卒業大会で大きくウケる確率が跳ね上がる |
| 言葉の魔術師 | 言葉選び＋伏線回収 | 1年目の賞レースで上位に残りやすい |
| 一発屋の素質 | 顔芸＋リアクション芸 | 1年目にブレイクするが翌年失速（一発屋ルート） |
| 劇場の主 | 量産型＋鋼のメンタル | 1年目に劇場メンバー入りしやすい |
| 時代の寵児 | SNS上手＋ひな壇の鬼 | 1年目のテレビ・SNSルートが一気に開く |

### コンビとしての相性
- 相方にも芸風スキルがある。2人の組み合わせで「**コンビ技**」が発動する（例: 自分が「早口」、相方が「間の取り方」→「緩急」でウケ量アップ）
- 相方がクセを持っていることもあり、そのフォローがイベントになる

## 2. キャラクリ（入学前の5ステップ）

1プレイ20〜30分なので、キャラクリは1分以内で終わる量にする。毎回作り直すのが面倒な人のために「前回と同じ」「おまかせ」ボタンを置く。

| ステップ | 選ぶもの | ゲームへの影響 |
|---|---|---|
| 1. 名前 | 名前・ふりがな、呼ばれ方（例: 「ハヤシ」「はやっさん」） | イベントの台詞で呼ばれる |
| 2. 見た目 | 髪型（8）、髪色（6）、顔（目・眉・口から各5）、体型（3）、服（6） | 見た目のみ。ただし「顔芸」系イベントの台詞が少し変わる |
| 3. 経歴 | 下の表から1つ | 初期能力・初期スキル・所持金・イベントが変わる |
| 4. 出身 | 地元組／上京組 | 上京組は家賃がかかるがハングリーさで成長が早い。方言を話すかどうかも選べる |
| 5. 担当 | ボケ／ツッコミ、得意にしたいもの（漫才／コント） | 伸びやすい能力と、相方候補の顔ぶれが変わる |

### 経歴（初期案 8種）
| 経歴 | 初期の強み | 初期のクセや弱み | 特有イベント |
|---|---|---|---|
| 高校出たて | 体力、伸びしろ（成長ボーナス） | お金が少ない | 親から仕送りの電話 |
| 大学生（ダブルスクール） | 発想力、言葉選び | 体力が減りやすい | 試験期間とネタ見せが重なる |
| 元会社員 | 所持金が多い、人たらし | 理屈っぽい | 元同僚がライブに来る |
| 高学歴 | 発想力が高い | 講師に「帰れ」と言われ続ける | 教授や親と衝突 |
| 元バンドマン | 度胸、声がデカい | 浪費家 | 元バンド仲間との再会 |
| 元体育会 | 体力、早起き | 表現力が低い | 罰ゲームで本領発揮 |
| フリーター | 苦学生、対応力 | 遅刻魔 | バイト先の店長が支えてくれる |
| 社会人（40歳） | 鋼のメンタル | 体力が低い、口を触る癖 | 最年長として同期の相談役になる |

経歴はどれも調査メモの実話（高学歴で面接官にいじられた、40歳で入学した、など）をもとにしている。
