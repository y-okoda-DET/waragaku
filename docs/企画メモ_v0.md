# お笑い養成所サクセスゲーム 企画メモ v0（壁打ち用）

最終更新: 2026-10-16　ステータス: **古い版**。最新はClaude Docsの「ワラガク！ 企画書 v1」。このメモは経緯の記録として残す

## 確定事項（2026-10-15）

- 遊ぶ場所: ブラウザ（スマホ縦画面優先）
- 長さ: 1年制・週ごと約40ターン・1プレイ20〜30分
- 芸の形態: コンビ固定、相方は入学後に決まる
- ネタ作り: 「ツカミ・展開・オチ」をカードで組み立てる
- お金: 完全無料・広告なし
- シナリオ: 実在の大手養成所の1年間のスケジュールを徹底リサーチして下敷きにする。固有名詞はすべて架空にする → [シナリオ案_1年間.md](シナリオ案_1年間.md)、調査は [research/](research/)
- 卒業大会: 在学中の2月に置き、1年間の最終決戦にする（2026-10-16）
- 特殊能力にあたる「芸風スキル」と、入学前の簡単なキャラクリを入れる → 最新は [設定書_v1.md](設定書_v1.md)
- リアリティ最優先（通っていた人・芸人・お笑いファンが「あるある」と言う水準）。大学お笑い出身の経歴と、先輩付き合いなどの人脈システムを入れる（2026-10-16）

## 1. コンセプト

- 一言で: 「お笑い養成所に入学した若手が、1年で“売れる芸人”を目指す育成シミュレーション」
- 参考体験: パワプロのサクセスモード（限られたターンでの練習選択、仲間とのイベント、最終的な能力査定）
- 差別化: 野球の試合の代わりに **ネタを作って舞台で披露する** のが山場。ネタの出来とウケ方が育成結果に直結する
- 遊び終わりの体験: 卒業時のリザルト → 「芸人1年目」の活躍ダイジェスト → SNSでシェアしたくなる結果画像

## 2. 論点と推奨案

### A. 配信形態・技術

| 論点 | 推奨案★ | 理由 | 代替案 |
|---|---|---|---|
| プラットフォーム | ★ブラウザゲーム（スマホ縦画面優先、PCも可） | URL一つで遊べて拡散しやすい。審査不要 | スマホアプリ（ストア審査・費用あり）／Steam |
| 技術 | ★TypeScript + React + Vite、静的ホスティング（GitHub Pages か Cloudflare Pages） | UI中心のゲームなのでゲームエンジン不要。無料で公開できる | Phaser、Unity、ティラノスクリプト |
| 収益 | ★まずは完全無料・広告なし | 「流行らせる」が目標なので遊ぶハードルを最小に | 広告、投げ銭、有料版 |
| セーブ | ★ブラウザ内保存（localStorage）、アカウントなし | サーバー不要で運用コストゼロ | クラウド保存・ランキング（後から追加可） |

### B. ゲーム設計

| 論点 | 推奨案★ | 理由 |
|---|---|---|
| 1プレイの長さ | ★20〜30分 | 何周も遊んでもらう前提。パワプロより短く |
| 在籍期間とターン | ★1年制（4月入学〜3月卒業）、1ターン＝1週、約40ターン | 実際の養成所も1年制が多くリアル |
| 芸の形態 | ★コンビ固定（相方は入学後にイベントで決まる） | 相方との関係がドラマの軸になる。ピン・トリオは後から追加候補 |
| 主人公の性格 | ★プレイヤーがボケ／ツッコミを入学時に選ぶ | 周回の動機になる |

**コアループ（推奨）**
1. 週の行動を選ぶ: 練習（後述の能力を伸ばす）／ネタ作り／バイト（お金）／休む（体力回復）／遊ぶ（同期と交流）
2. 月1回の「ネタ見せ授業」: 講師の前でネタを披露し、評価とアドバイスを受ける
3. 季節ごとの「校内ライブ」: 客前で披露。ウケ量が評価と人気に反映
4. 年度末の「卒業ライブ」: 最終試験。ここの結果で卒業後の所属・スタートが変わる

**ネタ作りの仕組み（推奨）**: ★パーツ組み合わせ方式。「設定」「ツカミ」「展開」「オチ」をカード的に選んでネタを組み立て、能力値と相方との相性でウケが決まる。カードはイベントや経験で増える。ここが本作の売りになる

**育成パラメータ（推奨・名称は独自）**

| 能力 | 意味 |
|---|---|
| 発想力 | ボケの面白さ、ネタパーツの質 |
| ツッコミ力 | ツッコミの鋭さ・ワード |
| 表現力 | 演技・声・間（ま） |
| 度胸 | 本番での実力発揮率 |
| 対応力 | アドリブ・フリートーク・大喜利 |
| 体力・メンタル | 行動の失敗率、不調イベント |

加えて「芸風スキル」（武器・クセ・極み）を習得していく。詳細は [芸風スキルとキャラクリ.md](芸風スキルとキャラクリ.md)

**仲間キャラ（推奨）**: 6〜8人で開始
- 相方候補 2〜3人（タイプ違い）
- ライバルの同期（エリート芸人の子、元会社員の苦労人 など）
- 厳しい講師、ゆるい講師
- 劇場の先輩芸人、バイト先の店長
- 各キャラに数段階の連続イベントがあり、進めると能力・芸風スキルがもらえる

### C. リザルトと「1年目」

- リザルト: 総合ランク（例: G〜S）、能力一覧、芸風スキル、コンビ名、代表ネタ
- 1年目の活躍（推奨）: ★テキスト＋簡易演出のダイジェスト（月ごとに数行）。劇場ランクの昇格、架空の賞レース予選の結果、テレビ初出演、SNSフォロワー数など。能力と芸風で展開が分岐し、まれに「1年目で賞レース決勝」の大当たり
- シェア: ★結果をまとめた画像を生成し、Xなどにワンタップで投稿

### D. 見た目・演出

| 論点 | 推奨案★ | 代替案 |
|---|---|---|
| 絵 | ★シンプルなオリジナル立ち絵（少人数）＋テキスト中心 | ドット絵、画像生成AI、外注 |
| 音 | ★フリー素材の効果音・BGM（ライセンスを記録） | 自作、無音 |

### E. 著作権・権利まわりの配慮

ゲームのルールや仕組み自体は著作権で守られないが、固有の名称・絵・UIの見た目は守られる。次を避ける。

- パワプロ固有の名称: 「サクセス」「パワプロ」「イベキャラ」「特殊能力」「査定」などは使わない。別の言い回しを用意する（例: 育成モード→「養成所生活」、特殊能力→「芸風スキル」）
- キャラデザイン: 2〜3頭身の丸顔キャラ（パワプロくん風）は避ける
- UI: パワプロの画面配置・配色・効果音を真似しない
- 実在の養成所（NSC、ワタナベコメディスクールなど）、事務所、劇場、芸人、賞レース（M-1、キングオブコント、R-1など）の名前は使わず、すべて架空にする
- 実在芸人のネタやギャグ、キャッチフレーズも使わない
- 素材のライセンスは一覧で管理する

### F. プロモーション（後で詳細化）

- リザルト画像のシェアを拡散の主軸に
- 開発過程をXで発信（ネタの一部、キャラ紹介）
- 公開時にお笑い好きコミュニティ、ゲーム紹介系アカウントへ告知
- 必要なら短い紹介動画（TikTok／YouTube Shorts）

## 3. 進め方（案）

1. 企画を固める（このメモ）
2. 最小版を作る: 1年分のターン、練習、ネタ見せ、卒業ライブ、リザルトだけ
3. 仲間キャラとイベント、ネタ作り、1年目ダイジェストを追加
4. テストプレイとバランス調整
5. 公開とプロモーション
