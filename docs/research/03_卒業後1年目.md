# 調査メモ: 養成所卒業後「芸人1年目」の実態

調査日: 2026-10-15。実在の固有名詞はリサーチ記録としてのみ残す。ゲーム内では架空名に置き換える。

（サブ調査の報告をそのまま収録。【確定】公式・報道／【準確定】Wikipedia等／【伝聞】本人発言・ブログ／【推定】計算・推測）

## 1. 所属と劇場ランク制度（吉本）

### 卒業から所属まで
- 【伝聞】卒業要件を満たせば吉本に所属。主ルートは若手劇場所属を目指すオーディションライブ（東京は2ヶ月に1回、数百組）。同期ライブ以外の収入は乏しく「一人暮らしの芸人はバイト漬け」（NSC東京29期・甘夏note）
- 【伝聞】3ヶ月ルール: コンビ結成から3ヶ月は舞台に立てない。在籍中の3月までに結成申請すれば対象外で4月から舞台可（同上）
- 【確定】4月入学・翌3月卒業の1年制。学費は入学諸経費11.5万＋授業料33万＋施設使用料5.5万＝約50万円。入学時に相方なし80%、お笑い未経験86%（NSC 2027年度パンフレット）
- 【確定】大ライブ（卒業公演）の時期が変動: 2024年は2月、2025年は5月に「1年目ルーキー」対象、2026年は4月（大阪4/8、東京予選4/9〜10・決勝4/22）。エリア校の生徒も出場。→ゲームでは「1年目4月のデビュー戦」として扱える
- 【準確定】大ライブ優勝特典の例: 2013年優勝者は4月の予定が全部仕事で埋まったスケジュール帳を贈られた

### 東京の若手劇場
- 【確定】2館体制: 芸歴9年目以上の上位メンバーが所属する劇場（2025年4月開館）と、8年目以下のメンバーが所属する126席の劇場（マイナビニュース2026/6/25）
- 【確定・報道】下位劇場のオーディションライブには500〜600組。勝ち進むと入れ替え戦→劇場メンバー入り（東洋経済）
- 【確定・報道】旧劇場では芸歴5年目以下が出られるライブが月3回ほど
- 【確定】「7年目以下の漫才師10組の観客投票バトル」等の企画ライブあり
- 【準確定】旧制度（2021〜）: レギュラー20組／ユース40組（毎月のカップ戦、3ヶ月に1度の決勝で優勝1組がレギュラー昇格）／それ以外は月1回のオーディションライブから

### 大阪の若手劇場【準確定】
- 下位「翔」・上位「極」の2区分。入口はオーディションライブを勝ち抜くこと
- 奇数月: 下位組とオーディション勝ち上がり組の入れ替え戦。基準順位で昇格・残留・降格
- 偶数月: 総合10位以内で上位メンバーに昇格
- 2026年4月から上位メンバーにも年間下位ポイントでの降格制度（3月確定）

## 4. ブレイク型と売れない1年目

- 一発屋ルート（実例: 4月デビュー→11月初テレビ→年末年始に12番組→2月CD・3月DVD→3月に最短記録で単独→年末には失速）
- 首席特典ルート（実例: 大ライブ優勝→4月の仕事が全部埋まる→地元で知名度）
- 在学中実績ルート（実例: 在学中に賞レースで結果→外部主催者からオファー、卒業4日目に初仕事）
- SNSルート（TikTok収益の2割天引き、YouTube収益の6割を取られたとの元芸人の証言）
- 売れない1年目【伝聞】: 2ヶ月に1回のオーディションで勝ち上がれない／同期ライブ・地下ライブは赤字か数百円／バイト漬け／解散・再結成で3ヶ月ルールの空白／劇場メンバー入りに5年かかった例も

## 5. 1年目の月別イベント（東京・2026年度想定）

| 月 | 主な出来事 |
|---|---|
| 4月 | 所属・芸歴1年目スタート。大ライブ（デビュー戦）。劇場オーディション挑戦開始。バイト生活 |
| 5月 | オーディションライブ（隔月）。同期ライブ。若手総合大会エントリー |
| 6月 | 若手総合大会の準決勝。漫才大会エントリー開始 |
| 7月 | コント大会1回戦。若手総合大会決勝。オーディションライブ |
| 8月 | 漫才大会1回戦開幕。コント大会2回戦・準々決勝 |
| 9月 | 漫才大会1回戦（多くの1年目はここで終わる）。コント大会準決勝 |
| 10月 | ピン芸大会エントリー。漫才大会2回戦。コント大会決勝（テレビで観る側） |
| 11月 | ピン芸大会1回戦。漫才大会3回戦・準々決勝 |
| 12月 | 漫才大会準決勝・決勝。劇場の年越しライブ（劇場メンバーのみ） |
| 1月 | ピン芸大会2回戦・準々決勝。オーディションライブ |

| 3月 | ピン芸大会決勝。次の期が卒業し初めて後輩ができる。上位メンバーの年度末降格 |

## 6. 他の養成所との比較

| 養成所 | 期間・学費 | 卒業後の所属 |
|---|---|---|
| 吉本（NSC） | 1年・約50万円 | 要件を満たせば所属→劇場オーディション |
| ワタナベコメディスクール | 1年（4月・10月生）。週4回39万円、関西校48万円。優秀者は学費免除 | 卒業後すぐ所属できるのは約1割（約150人中10組の例）。2024年から再挑戦ライブあり |
| 太田プロ（OEC） | 週1日2時間程度、年34万円 | かつては半年の試用期間で1期5組程度。現在はほぼ全員所属 |
| スクールJCA（人力舎） | 週3日（伝聞） | 所属方法は未確認。事務所の月例若手ライブが主な舞台 |
| 松竹芸能養成所 | 1年、4月・10月入学 | 卒業オーディション合格者のみ所属 |

ゲームでの描き分け案【推定】: 「全員所属・劇場で競争」型／「所属審査が狭き門」型／「少人数・ほぼ所属」型。
