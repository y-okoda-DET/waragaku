# 調査メモ: 大学お笑い（学生お笑い）出身者と、お笑い経験者の入学

調査日: 2026-10-16。27ソース。実名はリサーチ記録のみ、ゲームでは型に一般化して架空化する。

## 1. 学生お笑いの世界
- **サークル対抗の団体戦**（漫才・コント・ピンの3種目）: 決勝は大手事務所の劇場。チケット即完、スタッフも全員学生。2023年は168チーム。優勝特典は養成所の特別奨学金。「決勝の面子は養成所や劇場でまた会う」（https://brutus.jp/post-78404 、https://qjweb.jp/column/83947/）
- 「大学お笑いで一番大きな大会」は夏が個人戦、冬が団体戦。ほかに大学生の漫才大会（2004年〜）、学生芸人のテレビ番組（2011〜2015年頃が「転換点」）、16〜22歳限定のバトルライブ（優勝するとプロも出るライブへ）
- サークルの例: 早稲田（「大学お笑い界のよしもと」と言われるサークル、ネタ見せは週2回）、慶應、上智、一橋、明治、青学、日大の落研、大阪芸大の落研（高座名で呼び合い、今も先輩を高座名で呼ぶ。新入部員は「先代がすごかった」と映像を見せられる）、同志社
- 当事者は「大学お笑い」と名乗り、「学生芸人」は外部の呼び方（https://qjweb.jp/owarai/56574/2/）
- 「学生芸人って関東の大学中心に育った文化」。関西は大学生でも劇場オーディションからプロになれた（https://brutus.jp/brutuscope940comedy/）
- 専用劇場がないので会場を借りて自主ライブ。エントリーフィー制。大会で結果を出すと外部ライブに呼ばれる
- **現役学生芸人のあるある**（https://note.com/karasumizumizu/n/n839bacc079c1）
  - 初対面ではまずサークルを聞く。名乗りは「サークル○年の○○です」
  - 「デビューライブの時目立ってた人がもういない」
  - 「ピンネタライブの時、譜面台持ってる人がヒーローになる」
  - 「あ、あと無料カンパ制なのでカンパお願いします！」をMCが言い忘れる
  - 「大会でやるネタは2回までしか外でかけられない」
  - 「ライブに呼ばれるようになると迷走する」
  - 「コントをメインでやってる人が『見る分には漫才が好き』って言う」
  - 「アンケート記入用に分厚い板を持ってきてる人はだいぶ有能」
  - 「なんかツイート多いと嫌がられる」
- 掛け持ちが当たり前（複数ユニットで活動）。「4年で結果出さなきゃというプレッシャー」「1つ上にはその後が続かなかった子と少し馬鹿にされてる」

## 2. プロへのルート
- **A. サークル時代のコンビのまま養成所へ**: 飲み会で組んだ先輩後輩コンビが養成所で首席。団体戦決勝で劇場に立ち「めちゃくちゃ気持ち良くて」芸人を決意→首席卒業（父は医師で「そんなところにレールはない！」）。在学中に卒業大会で約330組の頂点、在学中にコント大会準々決勝。大会優勝で他事務所の養成所に特待生入学
- **B. 養成所に入らない**: 学生時代にスカウト（「いわゆるエリートコース」）。スカウトを断りアマチュアのまま漫才大会準決勝。学祭の大会で関係者に名刺をもらう。学生番組の制作会社に所属
- **C. 就職してから戻る**: 「学生時代の同期も、就職して、辞めて芸人に戻った連中がすごい多い」。「社会人お笑い」という流れ
- 挫折: 大学生の漫才大会で優勝したのに事務所オーディションで「君はツッコミの才能が無い」と言われて一度諦める
- ねじれ: 学生時代の仲間が養成所では「後輩」や「先輩」になる

## 3. 養成所での立ち位置
### 有利
- 「あの子ら大学で4年間やってるんやから、もう芸歴9年やで」「M-1獲りたいなら大学に行け！」。仲間同士で添削し合える環境は「芸人って実はこれがないのよ。全員ライバルやから」（https://toyokeizai.net/articles/-/729466?page=4）
- 豊富な舞台経験（https://toyokeizai.net/articles/-/830675?page=2）
- 講師から見て「もう別物でしたね…雰囲気でそう思わされた」（https://shuchi.php.co.jp/article/11828）
- 業界に知り合い: 「ADやってる友達が会議で名前出してくれるだけでもチャンスの幅が違う」
- 大卒という保険。「大卒ルーキーの時代が来てる」

### 不利（典型）
1. 「完成品」扱いで手をかけてもらえない: 「『仕上がってるね』と褒められるけど、アドバイスはあんまりもらえなくて」「完成しちゃってると、結果を出さないとサポートしてくれない」
2. 一般客にピントが合わない: 「4年間ゴリゴリにお笑い好きの学生芸人の前でネタをやり続けてきてるから」
3. インテリの色眼鏡: 「インテリネタとして作ったわけじゃないのに伝わらなかったり」。学歴を消せない「プライドと、諦めの悪さと、ずるさ」
4. 線が細い: 「頭で想像してる面白さを100で表現できる身体が備わっていない」（https://www.jprime.jp/articles/-/27308）
5. プライドでダメ出しを直さない: 「ずっと自分が1番面白いなあと思っていました」「ダメ出しをされても一回も直したことがありませんでした」→選抜に入れたのは「発声の授業だけでした」（https://note.com/gekkan_geinin/n/n939daee5aea4）
6. プロになった途端に伸び悩む。必要なのは「一芸」（https://gendai.media/articles/-/97226）
7. 相方が就職していなくなる: 「みんな卒業とともに就職するから、相方と一緒にプロに行けないことが多い」
8. 仕事と人間関係が地続き: 「立場を失ったらすべてを失う」
- 2010年代前半までの偏見: 「学生お笑いなんて恥ずかしいよ」「なんだよ、学生お笑いって」。今はブランドに。「大学お笑いやってたと人に言うのが恥ずかしかった」
- 「雑に括られるのが本当にイヤで、よくブチ切れてました」（https://oggi.jp/7424101）
- 今の世代はバトルライブに強く「勝ち負けに熱くなる」。「今の学生芸人のほうがうまい」

## 4. ほかのお笑い経験者
- 高校生の漫才大会: 優勝で養成所の入学金免除。高校時代に大会で話題になった人を見て「絶対にオレのほうが面白い」と翌年出場、そこで初対面→後にコンビ（https://news.livedoor.com/article/detail/15738704/）
- 18歳未満の受け皿として事務所系の高校がある
- アマチュアのまま賞レース: 「その日唯一のアマチュア」として1回戦合格
- 学生のうちからプロも出るバトルライブに出る
- 大学と養成所の掛け持ち
- 「お笑いの感性は大学お笑いで、芸人としての所作は養成所で学べる」。養成所は「個性の部分が死んでしまう人も多かった」。大学お笑いに4年浸かって辞めると「ただの無職」（https://note.com/kikuconte/n/nc1db64807f69）
- 「『なること』が目標なのは結構まずい」「1番まずいのが『社会人になるのが嫌だから』」
- 養成所は「未経験からでも」が前提で相方探しの会がある。経験者は「すでにコンビ・知り合いが多い」点で噛み合わない
- 「サークルでお笑いをしていましたが授業でウケるたびに自分の未熟さを知り」（他事務所の養成所生）

## 5. 一般化した型
1. エリート首席型 2. プライド空回り型 3. 学歴の呪縛型 4. スカウトでショートカット型 5. 相方が就職して喪失型 6. 社会人から出戻り型 7. 顔が広い型（関係のねじれ） 8. 玄人ウケに最適化された型（線の細さを後から矯正）
