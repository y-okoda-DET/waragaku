# 調査メモ: 大手お笑い養成所（吉本NSC 東京・大阪）の公式・公開情報

調査日: 2026-10-15。実在の固有名詞はリサーチ記録としてのみ残す。ゲーム内では架空名に置き換える（[シナリオ案](../シナリオ案_1年間.md)の対応表を参照）。
確度: [公式] 公式サイト・パンフ・プレスリリース／[報道] 吉本運営メディア・ナタリー等／[伝聞] 卒業生の体験談・Wikipedia（時代を併記）

## A. 入学まで

| 項目 | 内容 | 確度 |
|---|---|---|
| 入学資格 | 18歳以上または高卒（見込）以上。年齢上限なし | 公式 |
| 募集 | 2027年度は2026/9/1開始。締切は12月末・2月末・3月末の3回（2026年度は4回、さらに4月末まで延長） | 公式 |
| 選考 | 書類→グループ面接（コンビは揃って受ける）。選考料5,500円。基準は非公開 | 公式 |
| 合格率 | 「名前と『はい』が言えて学費が払えれば入れる…99%」 | 伝聞（2012年頃） |
| 学費 | 入学諸経費11.5万＋授業料33万＋施設使用料5.5万＝50万円。面接後2週間以内に一括 | 公式 |
| 在籍 | 4月入学・翌3月卒業の1年制 | 公式 |
| 構成比 | 男性88%・女性12%、入学時ひとり80%、お笑い未経験86% | 公式 |
| 説明会 | 人気芸人の体験授業、卒業したての先輩との座談会 | 公式 |

## C. 時期に縛られない事実

- 授業: 週4〜5コマ、月〜金中心で土日もありうる。1コマ45〜210分。翌月の予定は前月中旬に配布、急な変更あり [公式]
- ネタ見せが授業の約4割 [公式]
- 授業の種類: ネタ見せ、ネタ作り、即興、コント、新喜劇、トーク・大喜利、ダンス・自己解放、配信番組収録、発声・滑舌、賞レース特別授業（毎月）、芸人の心得・衣裳 [公式]。「日舞」「筋トレ同然のボイトレ」も [伝聞]
- 「講師はほとんど理論を教えず、ネタを作ってこいと言って酷評されて終わり」 [伝聞]
- 講師: 芸人、放送作家、漫才作家、演出家、舞台俳優、振付師。芸歴の長い先輩芸人が「相談役」として付く [公式]
- ネタ見せは並んだ順。授業内に見てもらえるのは15組前後。卒業間際は4時間前から並ぶ人も。並ばないことも評価を下げる [伝聞・2012年頃]
- 首席制度は2011年度から。「首席は売れない」ジンクスも [伝聞]
- 退学: 一括払いになってから中退は少ないが「来なくなる人は多数」 [伝聞]
- 校内ルール: 授業20分前にいないと遅刻、アクセサリー禁止、同期以外の全員に毎回挨拶、最寄り駅周辺1駅は自販機も禁止、生徒同士の恋愛禁止 [伝聞・2012年頃]
- 所属: 3月に所属説明会。卒業後1年目も学校がイベント・ライブで支援。大多数が所属 [公式／伝聞]
- コース: 現在は芸人のみ。作家は別の学校（以前は作家コースがあり興行実践で合同） [公式／伝聞]

## D. 2020年代の変化
- 2020年: コロナ禍でネタ見せ授業をYouTube生配信、オンライン＋少人数対面に
- 学費: 長く40万円 → 2022年までに50万円
- 2025年〜: 大ライブが卒業前の首席決定戦から卒業後の「お披露目」に
- 2026年5月: 地方5校の2027年度募集停止、東京・大阪に集約
- 2027年度: 募集3回、前期・後期の二期制、後期に選択授業
