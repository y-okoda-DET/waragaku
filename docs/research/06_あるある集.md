## 1. 芸人あるある（若手の日常）

### ネタ合わせ・ネタ作りの場所
- 夜中の公園。人の気配がしたら「ちょっと止めよか」。ヤンキーに「あいつら芸人ちゃうん？」。夏の短パンは蚊で「パイナップルみたいな足」。数年後には劇場の中で合わせるようになる（https://note.com/gekkan_geinin/n/n66b6c8aa79fb）
- 夜の公園で動いていると警察に声をかけられる（https://news.mynavi.jp/article/comedian-8/）
- 喫茶店で相方が5時間遅刻。カレーを一口食べて「ちょっと辛すぎますね」「じゃ、帰りますか！」（https://note.com/gekkan_geinin/n/n6f49a0e1ccf4）
- 「ファミレス行かへん？」がネタ合わせの合図。ある日それで呼ばれたら「俺、作家なるねん」で解散（https://post.tv-asahi.co.jp/post-689526）
- 深夜のファミレスで「お笑い向いてないのかな…」と泣く（https://news.mynavi.jp/article/comedian-12/）
- 平日はバイト、ネタ合わせは土日の公園（https://cocotame.jp/series/019226/）
- 「家が近いからネタ合わせしやすい」で組む
- 深夜のカラオケバイトは暇。相方と同じ店なら裏でネタ合わせ（https://sekatsuku-recruit.jp/archives/1045）

### 相方・お金
- ネタを書かない側に限って「新ネタやろう！」と言い、本人がネタを飛ばす。袖で責めたら3時間無視（https://tvablog.tv-asahi.co.jp/reading/logirl/3023）
- 相方に借りた金を返さず、本番前だけ現れてすぐ消える（https://news.livedoor.com/article/detail/26736391）
- 解散と再結成を繰り返す不仲コンビ（https://jisin.jp/entertainment/entertainment-news/2171068）
- 解散は寄席の合間に突然「続ける自信がない」
- ギャラは事務所の取り分を引いて折半

### コンビ名・改名
- 案を出し合ってトーナメントで決める。20案ずつ出して1つだけかぶる。表記（カタカナかひらがなか）で数時間揉める（https://www.owarai.yrzygs.com/name-origin）
- バイト先の資材名がコンビ名に。占い師の勧めで改名したら営業先で「誰なん？」と言われて元に戻す（https://magazine.fany.lol/62435）
- 相方に相談なく本番の紹介でコンビ名が変わっていた。番組企画で突然改名させられる

### 衣装・出囃子
- 衣装は売れ具合で変わる: 卒業直後は卒業式のスーツでネクタイの結び目が巨大 → 1年目はサイズの合わない安いジャケット → 劇場入り直前は黒のブーツと古着屋の明るいジャケット → 安いオーダースーツで襟の色に個性 → 百貨店の吊るし → スタイリスト（https://www.walkerplus.com/article/1221013）
- スーツに替えると「なめられなくなる」が、最初は見た目に中身が追いつかずウケが落ちる（https://number.bunshun.jp/articles/-/852823?page=2）
- コントは小道具・衣装の経費がかかる。「準備ができなくてやめたネタもたくさん」「漫才は準備が楽」
- 出囃子は「名刺代わり」。数秒しか流れず、鳴った時点で舞台は始まっている

### ライブ・地下ライブ・チケット
- 誰でも出られるライブのエントリー料はコンビ2000〜3000円、ピン1000〜2000円。ネタ2〜4分。客投票1位が上のランクへ進む「ランク制」、入れ替え戦（https://note.com/toffee101/n/n3f48144ac982）
- 受付で初めてエントリー料5000円と知る。優勝賞金10万円、客席5〜6人。初舞台でスベって料金のことで頭がいっぱい（https://qjweb.jp/column/50495/2/）
- 主催者は区の施設を1万円で借り、出演料と入場料で利益。芸人は「金を払ってでも出たい」（https://www.moneypost.jp/273384/2/）
- 劇場出番は1人167円、交通費1100円で赤字。最初は月1回60秒、勝ち残ると3分・月3回
- 地下にはランクアップの道筋。同期の初出演が決まると一緒に喜ぶ（https://bunshun.jp/articles/-/44941）
- 地下は尖ったネタでコアなファンを掴む
- スベりすぎて客に通報され警察が来た（https://gendai.media/articles/-/98716）
- 手売り: 劇場内やエレベーター前で売る。客にとっては話せて写真も撮れる（https://www.jprime.jp/articles/-/6983）
- 先輩の単独は若手総出で2週間ノーギャラ。差し入れの高級菓子を持ち帰れたら「ラッキー」

### 楽屋・上下関係・打ち上げ
- 挨拶は「◯期の××です」。1日でも早く入れば先輩
- 終演後の作家のダメ出しは並んだ順で長く、終電を逃す。「このあとメシ行こう」が先輩付き合いの最大のチャンス（https://waramaru.jp/waiting）
- 夜でも「おはようございます」
- 「同期のケツは同期で拭く」。年齢や売れ方に関係なく芸歴で上下（https://waramaru.jp/sync/）

### バイト・生活
- 定番: 居酒屋、カラオケ、深夜コンビニ、イベントスタッフ、ティッシュ配り、フードデリバリー、引越し、警備、コールセンター、バーテンダー、エキストラ。芸人仲間がいる職場ならシフトを代わってもらえる。コールセンターで「伝説の社員」になる芸人も
- アラフォーのバイト: ファミレスで同世代の客にやるせなくなる、カラオケで大学生に「おじさん頑張れ！」、引越しの翌日は寝たきり、コールセンターは座っていられて落ち着く（https://www.moneypost.jp/257031）
- 風呂なしアパートで3分200円のコインシャワー。床が傾いていてビー玉が転がる（https://wanibooks-newscrunch.com/articles/-/3251）
- 1000円カットに通っているのを隠していた
- 「本当に売れていない芸人は、バイトを多くしているので食えている」（https://note.com/kikuconte/n/n130267649709）
- 行きつけの居酒屋で1500円を置いて「過ぎたらストップって言ってください」。マスターの「売れない」が当たる

### 賞レース予選
- 2分漫才。約10組ずつのグループ。全組終わるまで8時間の日も。結果はその日のうちに公式サイト等で。審査員は主に作家（https://kim-magazine.com/post-9053）
- 1回戦体験記: 受付で2000円、番号入りのシールを胸に。「デコ出した方が売れる」噂を信じて髪を上げる。控室は廊下で約30人、前の組の声が聞こえる中で小声のネタ合わせ。客と目が合って頭が真っ白、出来は練習の30%（https://www.wantedly.com/companies/loglass/post_articles/463771）
- 参加料は売れっ子でも受付で払う
- 1回戦の各日上位はネット動画で公開される
- 予選には2〜3本のネタを持ち込み、勝負ネタは準決勝で

### ウケ・スベリ・エゴサ
- 知り合いで満員にした90分単独でずっとスベる。身内の一角だけウケる。冒頭でネタを飛ばし手を合わせて謝ったら会場全体が不安に。終演後は口内炎が5、6個。今も仲間にイジられる（https://lp.p.pia.jp/article/news/263685/index.html）
- エゴサ: 手応えがあった日ほど検索して眠れない。タクシーで良い投稿が見つかるまで降りられない。1日60回。「◯◯さん」だと丁寧な悪口、「◯◯ちゃん」だと褒め言葉。本番前にエゴサして揺れる
- 気にしない派: 「誰が言うか」で価値が変わる
- アンケートは終演後に真っ先に読む。細かい通、一言だけの人、全員を丸文字で褒める人。読まない芸人もいる

## 2. 養成所に通っていた人のあるある（追加分）
- ネタ見せの順番は早い者勝ち。1時間前から階段に並ぶ。1組1〜2分、枠は10〜20組（https://waramaru.jp/nsc-characteristic/）
- 学校周辺の飲食店は禁止（昔、酔った生徒が窓ガラスを割った）。授業後は隣駅か大学の構内に集まる
- 相方探しの会は街コン方式。カンフーや英語ネタの授業。ダンスの授業が体力的に一番きつく、下手だと真面目に踊ってもふざけて見える
- 前日に講師の都合で休講（バラシ）。教室が足りずホールを交代で使う
- 1年の体感（https://monzzy.tokyo/post-1022/）: 4月は初回に2分ネタを持っていくと有利／6月は8〜10人の集団コント／7月に辞める人が出始める／8月は漫才大会1回戦の結果を講師に報告（約4割通過）／9月の合宿の頃には生徒数が半分／10月は警察関係者のコンプライアンス講習と選抜クラス編成／11月に同期の「光と影」がはっきり分かれる／12月東西対決／1月は卒業公演のオーディション（ネタ、ダンス、発声、演技、その他大勢）／3月卒業公演
- 選抜入りのコツは目立つこと。最前列、ネタを一番に出す
- ダメ出し「言わされてる感がある」「学芸会ではない」。前の組とテーマがかぶって笑いが起きても緊張で気づかない。終わった後は放心（https://note.com/tamago0728_neko/n/nd151fd85507c）
- 「同期のネタで笑ってはいけない」授業と、笑ってよい授業。授業中ずっと牛丼を食べ続けさせられた生徒
- 入学者約600人、15〜60歳。卒業時には半分以下。入試は30秒の自己PRだけ（時代による）
- 期番号は東西で違う（東京26期＝大阪43期）。入り直した人の「隠れ芸歴」
- 同期と本当に仲良くなるのは卒業してから。生き残りが減るほど絆が強くなる
- 同期の大型LINEで52人全員既読スルー、ショックで退会（https://www.daily.co.jp/gossip/2018/12/07/0011884141.shtml）
- 当たり年の期には「花の◯期」と名前がつく
- ピンで入った生徒は声をかけ合いモテる。旅行中に組みたかった相手を取られた。授業ごとに相方を変える。1分ネタライブのアンケート1位で選抜へ
- 一人喋りの授業で100点満点中4点

## 3. お笑いファンのあるある
- 出囃子が鳴っただけで次のコンビが分かる。暗転中に運ばれるセットでネタが分かる。アドリブがどこか分かる（https://girlschannel.net/topics/1506034/）
- 「売れる前から知ってた」。事務所・芸歴・先輩後輩の関係を覚えている。コンビ仲を親戚並みに気にする。解散ニュースで落ち込む
- 周りにお笑い好きがいない。賞レースは一年中。ライブが安くて気づくと出費がかさむ。世間の「若手」はオタクから見ると中堅（https://note.com/hiyoko_owarai/n/nb61757a9dd8f）
- チケットの買い方: 公式サイト（前方席狙い、手数料あり）／手売り（芸人にDMして当日直接買う、話せる）／置きチケ。地域で手売りのスタイルが違う（https://note.com/owarai_1113_/n/nccc4b64c36cc）
- ロビーの手売り芸人の前で開場を待つのが気まずい。目を伏せてスマホを見る
- 出待ち: 常連は1〜2時間待っても涼しい顔。近隣の店の前で待つと苦情。芸人側も楽屋口を出る瞬間が勝負、先輩にだけ出待ちがいないと気まずい。差し入れの缶コーヒーは冷めがち。芸人は具体的な感想を聞きたい（https://waramaru.jp/waiting）
- 出待ちが「禁止」の空気になった理由: 近隣の苦情、サービス残業。ロビーの手売りや交流は許されやすい
- 女性芸人への出待ちおじさん問題（「女芸人は守ってもらえない」）
- 通学路に劇場があって通うように。芸人のトレカを劇場前で交換、超レアカードがフリマで高値（https://www.moneypost.jp/1139130）
- 「繋がり目的」と見られることへの反発
- 配信チケットのアーカイブを寝る前に観る。評判を見てから買える
- 漫才大会3回戦の観覧: 座席は当日朝にアプリで。1ブロック約35分、休憩は15分の1回だけ。椅子が硬く後半はお尻が痛い。休憩中に気になったコンビを検索（https://note.com/kimono_to/n/n9fe5643807e4）
- 予選は3回戦が一番面白い。動画で約300組を全部観る。名前も知らない組が会場を揺らす瞬間が醍醐味。1〜2年後に決勝に来る「青田買い」感（https://crea.bunshun.jp/articles/-/39630）
- 予選のネタを10年記録し続ける人。アンケートを感謝の気持ちで毎回書く人
- 女性客が増えると票の入り方が変わる
- 劇場を卒業するとき「劇場にいる間にどれだけファンを付けられるか」

## 4. 調査担当の演出案（抜粋）
- 挨拶ボタンは時間帯に関係なく「おはようございます」
- エントリー画面「エントリー料 2,000円／ネタ時間 2:00」。所持金不足で「バイトのシフトを増やしますか？」
- 予選の結果画面は「公式サイト更新待ち…」→ 自分の名前が「ない」ことで落選を伝える
- 控室のステータス「前の組の声が聞こえる」「小声ネタ合わせ中」「胸の番号シール」
- スベったら無音のSE、終演後に口内炎アイコン、長く残る称号「伝説の大スベり単独」
- エゴサ画面: 検索ワードで結果が変わる、タクシーメーターが上がり続ける
- アンケート束: 通／一言／丸文字の全褒め
- 実績「売れる前から知ってた」「出囃子だけで分かる」
